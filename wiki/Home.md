# NATO alphabet

🌐 **English** · [Dansk](Home-da) · [Bahasa Melayu](Home-ms)

A console tool that spells a word with the NATO phonetic alphabet. It is the Day 26 assignment of Udemy's "100 Days of Code: The Complete Python Pro Bootcamp" and shows list and dictionary comprehensions. It needs Python 3.13 or newer and has no runtime dependencies.
